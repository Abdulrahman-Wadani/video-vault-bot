# Video Vault

A private Telegram bot that turns a chat into a video archive. Send it a link from TikTok, YouTube, X, Instagram, Reddit or any of the 1,000+ sites supported by [yt-dlp](https://github.com/yt-dlp/yt-dlp); it downloads the video and posts it back into the chat with the title, the uploader and the original link.

Runs on a home server in Docker.

## Features

- **Uploads up to 2 GB** – uses Telegram's MTProto API through [Telethon](https://github.com/LonamiWebs/Telethon) instead of the Bot API, which stops at 50 MB.
- **Plays in the chat** – videos are sent as streamable MP4 (H.264/AAC preferred, capped at 1080p) with duration, dimensions and a thumbnail generated by ffmpeg.
- **Private** – only the Telegram user IDs in `ALLOWED_USER_IDS` are served; everyone else is ignored. A setup mode tells you your ID on first run.
- **Several links at once** – links are queued and processed one at a time with live progress (downloading → uploading %), so a small server stays responsive. Posts with several videos (e.g. X, Instagram carousels) send up to 10.
- **Leaves nothing behind** – each job works in a temporary folder that is deleted after sending; leftovers from an interrupted job are cleaned on start-up.
- **Translatable** – drop a `messages.json` with the same keys into the data folder to change the bot's replies.

## Setup

You need Docker, a bot token from [@BotFather](https://t.me/BotFather), and an `api_id` / `api_hash` from [my.telegram.org](https://my.telegram.org) (API development tools). Both are free.

```bash
git clone https://github.com/Abdulrahman-Wadani/video-vault-bot.git
cd video-vault-bot
./setup-env.sh          # asks for the token, api_id and api_hash; writes .env (mode 600)
docker compose up -d --build
```

Send `/start` to your bot. It replies with your user ID; put it in `.env`:

```
ALLOWED_USER_IDS=123456789
```

and restart with `docker compose up -d`.

## Configuration (`.env`)

| Variable | Default | Description |
|---|---|---|
| `BOT_TOKEN` | – | Token from @BotFather |
| `API_ID`, `API_HASH` | – | From my.telegram.org |
| `ALLOWED_USER_IDS` | empty (setup mode) | Comma-separated Telegram user IDs |
| `MAX_FILE_MB` | 1950 | Largest file the bot will send |
| `MAX_HEIGHT` | 1080 | Highest resolution to download |

Optional files in `data/`:

- `cookies.txt` – Netscape-format cookies, for sites that need a login (often Instagram).
- `messages.json` – your own wording or language for the bot's replies.

## Keeping it working

Sites change often. When one stops working, rebuild to get the latest yt-dlp:

```bash
docker compose build --pull --no-cache && docker compose up -d
```

## Project structure

```
bot.py            Telegram handlers, download queue, yt-dlp and ffmpeg helpers
setup-env.sh      Writes .env without echoing secrets
Dockerfile        Python 3.12 + ffmpeg, runs as a non-root user
requirements.txt  Telethon, cryptg, yt-dlp and Deno (needed by yt-dlp for YouTube)
compose.yaml      Runs the bot with restart: unless-stopped
```
